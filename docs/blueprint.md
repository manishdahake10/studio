# **App Name**: Weather Weaver

## Core Features:

- Real-time Weather Display: Display real-time weather data, including temperature, humidity, wind speed, and visibility, using the WeatherAPI API.
- City Search: Allow users to search for weather by city name using an integrated search bar.
- 7-Day Forecast: Display weather forecasts for the upcoming 7 days.
- Theme Toggle: Users can switch between light and dark themes to customize the app's appearance based on preference.
- AI Weather Summary: Use AI to dynamically generate concise weather summaries. The LLM is used as a tool to determine whether, when and how to incorporate current location or day of the week information into the summary. If it rains every Tuesday then knowing today is Tuesday is irrelevant, and it would be irrelevant to point it out if it always rains in that city

## Style Guidelines:

- Primary color: Saturated teal (#4DB6AC) for a calming, weather-themed, and modern feel.
- Background color: Light grayish-teal (#E0F2F1) for a clean and unobtrusive backdrop.
- Accent color: Muted blue (#79A7D3) for interactive elements, providing a subtle yet distinct contrast.
- Body and headline font: 'Inter' (sans-serif) for a clean, modern, and readable UI.
